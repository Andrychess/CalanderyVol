# Календарь мероприятий (VK Mini App)

Карточки мероприятий и заявки участников хранятся в [JsonBox.ru](https://jsonbox.ru) в одном JSON. Создавать и редактировать могут пользователи с ролью в сообществе VK: **создатель**, **администратор**, **редактор**, **модератор**.

## Быстрый старт

### 1. Регистрация на JsonBox

**Самый простой способ:** откройте `jsonbox-register.html`, введите почту и нажмите «Зарегистрироваться».

```bash
npx serve .
```

### 2. Первичная загрузка данных (опционально)

```bash
curl -X POST "https://jsonbox.ru/api.php?action=store" \
  -H "Content-Type: application/json" \
  -d "{\"api_key\":\"ВАШ_ПОЛНЫЙ_КЛЮЧ\",\"data\":{\"events\":[],\"enrollments\":[]}}"
```

### 3. Настройка `config.js`

```bash
copy config.example.js config.js
```

| Поле | Описание |
|------|----------|
| `JSONBOX_API_KEY` | Полный ключ |
| `JSONBOX_API_KEY_READONLY` | Ключ `ro_...` |
| `VK_APP_ID` | ID mini app |
| `VK_GROUP_ID` | ID сообщества |
| `DEV_ADMIN_PASSWORD` | Пароль для теста вне VK |
| `DEFAULT_*` | Шаблоны полей новой карточки (функционал, условия, место, кнопка) |

### 4. Локальный запуск

```bash
npx serve .
npm test
```

### 5. VK Mini App

Укажите URL деплоя в настройках приложения VK. Открывайте mini app **из сообщества**.

## Данные в JsonBox

```json
{
  "events": [
    {
      "id": "ev-1",
      "title": "Название",
      "schedules": [{ "date": "2026-05-24", "time": "18:00", "timeEnd": "20:00" }],
      "level": "региональный",
      "plan": { "published": false, "regulationDays": [], "volunteerDays": [] }
    }
  ],
  "enrollments": [
    {
      "id": "enr-ev-1:12345",
      "eventId": "ev-1",
      "userId": 12345,
      "status": "pending",
      "updatedAt": "2026-06-01T12:00:00.000Z"
    }
  ]
}
```

Уровни: `вузовский` | `городской` | `региональный` | `межрегиональный` | `всероссийский` | `международный`.

Прошедшие мероприятия автоматически **сжимаются** (остаются id, название, даты, уровень).

## Возможности

- Список, календарь, фильтры (одно меню), избранное, архив прошедших (админ)
- Расписание: регламент, волонтёрские смены, участники и статусы заявок
- «Посещённые» и оценочные баллы (только **подтверждённые** прошедшие мероприятия)
- Резервная копия JSON и экспорт заявок CSV (админ)
- Черновики формы мероприятия и расписания в `localStorage`
- Предупреждение при конфликте сохранения в JsonBox

## Безопасность

Полный `api_key` в фронтенде — компромисс без своего сервера. Для роста проекта: прокси (Vercel/Cloudflare) с проверкой подписи VK и записью только от админов. Не коммитьте `config.js` с реальными ключами.
